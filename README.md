# 💼 CV Online — Marcelo Moreno

Currículo online em formato de site, feito à mão com **HTML, CSS e JavaScript puros** (sem frameworks). Apresenta o perfil, experiência, competências, projetos e contactos de Marcelo Moreno.

🔗 **Site publicado:** https://marcelomorenodeoliveira-hash.github.io/MeuPortfolio/

---

## ✨ Funcionalidades

- Perfil, experiência e competências em secções organizadas
- Barras animadas de competências técnicas
- Botão **Mostrar Competências** (lista interativa)
- Contador animado de estatísticas
- Menu responsivo (hambúrguer) para telemóvel
- Formulário de contacto com validação
- Botão para **guardar o CV em PDF** (`window.print`)
- Layout totalmente responsivo
- Efeitos de revelação ao fazer scroll (Intersection Observer)

## 🧰 Tecnologias

| Tecnologia | Utilização |
|---|---|
| HTML5 | Estrutura e semântica |
| CSS3 | Layout, design responsivo, animações |
| JavaScript (ES6+) | Interatividade: menu, animações, formulário, contadores |

## 📁 Estrutura

```
teste/
├── index.html   → estrutura e conteúdo do CV
├── style.css    → estilos e design
└── script.js    → interatividade e animações
```

## 🚀 Como usar

1. Descarrega ou clona este repositório;
2. Abre o ficheiro `index.html` em qualquer navegador;
3. Para editar o teu CV, altera os textos em `index.html` (nome, email, telefone, experiência, competências).

> Podes também hospedar gratuitamente no [GitHub Pages](https://pages.github.com/) — é onde este site está publicado.
